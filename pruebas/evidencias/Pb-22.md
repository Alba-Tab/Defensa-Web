# Pb-22 — Detalle de incidente en el panel

Fecha de implementación: 20 de septiembre de 2026.

## Resultado

- `/` redirige a `/login` sin una sesión válida.
- `POST /api/auth/sesion` emite una cookie `HttpOnly`, `SameSite=Strict`; la API móvil conserva Bearer.
- El panel lista incidentes con los filtros de Pb-21 y abre el detalle en un diálogo accesible.
- El detalle muestra resumen, etiqueta de origen, ficha y eventos relacionados.
- URL, parámetros, firmas e informe se asignan mediante `textContent`; nunca se interpretan como HTML.
- Todos los recursos de Jinja2, Alpine.js, HTMX y Chart.js se sirven localmente.
