# Pb-15 — Límite de tasa

Fecha de implementación: 20 de septiembre de 2026.

## Configuración

- Zona general por IP real: 10 solicitudes por segundo, ráfaga de 20.
- Login `/rest/user/login`: 5 solicitudes por minuto, ráfaga de 4.
- Respuesta al exceder un límite: HTTP 429.
- Solo los proxies de loopback son confiables para `X-Forwarded-For`; los clientes directos no
  pueden sustituir su dirección.
- El log JSON incluye `limit_req_status` para separar rechazos volumétricos de otras respuestas.

La limitación ocurre en nginx antes de `proxy_pass`. No crea incidentes ni baneos y no sustituye
el motor de políticas de Pb-6.

## Verificación reproducible

La sintaxis se valida con `nginx -t` durante el aprovisionamiento y con:

```bash
docker run --rm \
  -v "$PWD/infra/nginx/defensa-web.conf:/etc/nginx/conf.d/default.conf:ro" \
  nginx:1.27-alpine nginx -t
```

Para una prueba aislada sin Juice Shop se puede montar también
`pruebas/nginx/upstream-mock.conf` en `/etc/nginx/conf.d/upstream-mock.conf` y ejecutar los
scripts k6 contra el puerto publicado por el contenedor.

En la VM del laboratorio, las pruebas k6 son:

```bash
BASE_URL=http://192.168.56.20 DURACION=10m VUS=2 ESCENARIO=pb15-legitimo \
  SUMMARY_FILE=pruebas/resultados/k6-pb15-legitimo.json \
  k6 run pruebas/k6/navegacion_legitima.js

BASE_URL=http://192.168.56.20 k6 run pruebas/k6/limite_tasa.js
BASE_URL=http://192.168.56.20 RUTA=/rest/user/login METODO=POST TASA=10 \
  k6 run pruebas/k6/limite_tasa.js
```

La primera prueba exige una tasa de respuestas 429 igual a cero. Las dos ráfagas exigen al menos
una respuesta 429 y una tasa de errores 5xx igual a cero. Los resultados JSON se guardan fuera de
Git junto con las mediciones de Pb-3 para distinguir la limitación de nginx de la latencia de
Suricata.

## Resultado aislado

Se validó la configuración con nginx 1.27 en Docker y el upstream local de prueba:

| Escenario | Solicitudes | Respuestas 429 | Errores 5xx | Resultado |
|---|---:|---:|---:|---|
| Navegación legítima, 2 VU durante 30 s | 120 | 0 | 0 | cumple |
| Ráfaga general, 30 req/s durante 5 s | 150 | 80 (53,33 %) | 0 | cumple |
| Login, 10 req/s durante 5 s | 50 | 45 (90 %) | 0 | cumple |

También pasó `nginx -t`. La ejecución prolongada de 10 minutos y la comparación de latencia con
Suricata requieren la VM Ubuntu del laboratorio; los comandos anteriores quedan preparados para
producir esa evidencia sin cambiar la configuración.
