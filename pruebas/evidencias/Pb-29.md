# Pb-29 — Terminación TLS inspeccionable

Fecha de implementación: 20 de septiembre de 2026.

## Diseño aplicado

- nginx publica HTTPS en 443 con un certificado autofirmado generado fuera de Git.
- HTTP en 80 responde `308` y conserva la ruta y la consulta.
- nginx termina TLS y reenvía HTTP a Juice Shop en `127.0.0.1:3000`.
- nftables envía ambos sentidos de ese tramo de loopback a NFQUEUE 0; Suricata inspecciona así el
  contenido ya descifrado.
- nginx agrega `X-Forwarded-For` y EVE usa XFF en despliegue `reverse` para conservar la IP real en
  `src_ip`.
- Las zonas de límite de tasa de Pb-15 están dentro del servidor TLS y mantienen la respuesta 429.

El canal móvil actual apunta a la API administrativa en 8000. No atraviesa el puerto 80 de nginx,
así que la redirección no lo corta; tampoco obtiene TLS con esta historia.

## Verificación automática local

Las pruebas comprueban el servidor 80/443, las rutas del certificado, TLS 1.2/1.3, la cola del
tramo descifrado, los cuatro parámetros XFF de Suricata, los permisos `0600` de la clave, los SAN
del certificado y que Git no siga claves ni certificados.

El ensayo aislado con nginx 1.27, upstream local y k6 0.54 obtuvo:

| Escenario HTTPS | Solicitudes | Respuestas 429 | Errores 5xx | Resultado |
|---|---:|---:|---:|---|
| Navegación legítima, 2 VU durante 5 s | 20 | 0 | 0 | cumple |
| Ráfaga general, 30 req/s durante 5 s | 151 | 81 (53,64 %) | 0 | cumple |
| Login, 10 req/s durante 5 s | 51 | 46 (90,19 %) | 0 | cumple |

También se comprobó una respuesta `308` con ruta y consulta conservadas, una respuesta HTTP/2
`200` del upstream a través de TLS, la recepción de la IP del cliente en `X-Forwarded-For` y la
carga correcta de la configuración XFF con Suricata 8.0.6. Esta prueba local confirma nginx y
Pb-15; no reemplaza NFQUEUE en Linux.

La sintaxis y el comportamiento de nginx pueden probarse sin guardar secretos en el repositorio:

```bash
DEFENSA_TLS_PERMITIR_USUARIO=SI \
  DEFENSA_TLS_DIR="$PWD/pruebas/resultados/tls" \
  infra/nginx/generar-certificado-lab.sh

docker run --rm \
  -v "$PWD/infra/nginx/defensa-web.conf:/etc/nginx/conf.d/default.conf:ro" \
  -v "$PWD/pruebas/resultados/tls:/etc/defensa/tls:ro" \
  nginx:1.27-alpine nginx -t
```
