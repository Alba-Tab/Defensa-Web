# Pb-25 — Estado de componentes en el panel

Fecha de implementación: 20 de septiembre de 2026.

## Resultado implementado

`GET /api/salud` expone `nginx`, `suricata`, `fail2ban` y `ollama`. En modo real los tres servicios
del host se consultan mediante `systemctl is-active`. Ollama se consulta mediante `GET /api/tags`
solo cuando `DEFENSA_OLLAMA_URL` está configurada; si no se define muestra `no_configurado`.
Una respuesta inactiva degrada el estado global sin impedir que el panel cargue.

El panel actualiza el bloque cada 30 segundos y también ofrece actualización manual.
