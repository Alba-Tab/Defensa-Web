# C-32 — Ollama en el anfitrión

Fecha de verificación: 20 de septiembre de 2026.

## Resultado

- Anfitrión: macOS arm64, Apple M5, 16 GB de memoria.
- Ollama: `0.34.2`, instalado nativamente con Homebrew.
- Servicio: `sh.brew.ollama`, configurado para escuchar en `0.0.0.0:11434` durante la
  sesión de demostración.
- Modelo inicial: `llama3.2:1b` (1,3 GB), descargado en el anfitrión.
- `GET http://127.0.0.1:11434/api/version` respondió `0.34.2`.
- `GET http://127.0.0.1:11434/api/tags` listó el modelo descargado.

La escucha en todas las interfaces permite que la VM consulte el servicio por la red host-only.
No se debe publicar el puerto 11434 en una red no confiable porque Ollama no incorpora
autenticación en este despliegue.

## Arranque reproducible

Desde la raíz del repositorio:

```bash
./infra/ollama/iniciar-anfitrion-macos.sh
```

El script fija `OLLAMA_HOST=0.0.0.0:11434`, reinicia el servicio, espera a que responda y
descarga `llama3.2:1b` si aún no está disponible. Para usar otro modelo:

```bash
DEFENSA_OLLAMA_MODELO=<modelo> ./infra/ollama/iniciar-anfitrion-macos.sh
```

Verificación final desde la VM:

```bash
curl http://<IP_ANFITRION>:11434/api/tags
```
